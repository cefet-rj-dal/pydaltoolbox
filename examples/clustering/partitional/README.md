# Partition-Based Foundations Examples

These examples are the fastest way to understand how `pydaltoolbox` represents unsupervised learners, cluster assignments, and evaluation outputs.

- [01-partitional-kmeans.md](01-partitional-kmeans.md) - `ClusterKmeans`: centroid-based clustering with Euclidean partitions.
- [02-medoid-pam.md](02-medoid-pam.md) - `ClusterPam`: medoid-based clustering, often more robust to extreme points.
