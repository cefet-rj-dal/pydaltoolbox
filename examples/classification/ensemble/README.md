# Ensemble Classifiers Examples

Classifiers that combine multiple base models to achieve more robust and generalizable predictions.

- [12-ensemble-random-forest.md](12-ensemble-random-forest.md) - `ClaRf`: ensemble of randomized decision trees.
- [15-ensemble-bagging.md](15-ensemble-bagging.md) - `ClaBagging`: bootstrap aggregation of tree learners.
- [16-ensemble-boosting.md](16-ensemble-boosting.md) - `ClaBoosting`: sequential ensemble that focuses on hard cases.
- [22-boosting-xgboost.md](22-boosting-xgboost.md) - `ClaXgboost`: gradient boosting classifier with `xgboost`.
