# Category Comparison Examples

These charts are useful when the main goal is to compare categories, summarize aggregates, or show composition.

- [01-comparison-bar.md](01-comparison-bar.md) - bar chart for aggregated values by category.
- [02-comparison-bar-with-error.md](02-comparison-bar-with-error.md) - bar chart with uncertainty or variability bands with explicit error bars.
- [03-comparison-grouped-bar.md](03-comparison-grouped-bar.md) - grouped bars for side-by-side category comparisons.
- [04-comparison-stacked-bar.md](04-comparison-stacked-bar.md) - stacked bars for composition within each category.
- [05-comparison-lollipop.md](05-comparison-lollipop.md) - lollipop chart as a lighter alternative to bars.
- [06-proportion-pie.md](06-proportion-pie.md) - pie chart for simple proportion summaries.
- [07-profile-radar.md](07-profile-radar.md) - radar chart for multivariate profile comparison.
