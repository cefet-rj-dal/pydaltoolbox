# Smoothing and Discretization Examples

These examples summarize continuous values into intervals, frequencies, or cluster-defined bins.

- [40-smoothing-interval.md](40-smoothing-interval.md) - `SmoothingInter`: discretization by equal-width intervals.
- [41-smoothing-frequency.md](41-smoothing-frequency.md) - `SmoothingFreq`: discretization by frequency-balanced bins.
- [42-smoothing-clustering.md](42-smoothing-clustering.md) - `SmoothingCluster`: class-aware discretization guided by clustering and the target label.
- [43-smoothing-generic.md](43-smoothing-generic.md) - `smoothing`: base family and tuning logic behind the smoothing variants.
- [44-smoothing-quantization.md](44-smoothing-quantization.md) - `SmoothingQuantization`: one-dimensional k-means quantization without class supervision.
