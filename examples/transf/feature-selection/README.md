# Feature Selection Examples

These examples reduce the predictor set according to relevance, sparsity, or subset search.

- [60-feature-selection-information-gain.md](60-feature-selection-information-gain.md) - `InfoGain`: rank predictors by information gain.
- [61-feature-selection-relief.md](61-feature-selection-relief.md) - `Relief`: rank predictors through nearest-hit and nearest-miss contrasts.
- [62-feature-selection-stepwise.md](62-feature-selection-stepwise.md) - `Stepwise`: GLM-based stepwise selection.
- [63-feature-selection-lasso.md](63-feature-selection-lasso.md) - `Lasso`: L1-based embedded feature selection.
- [64-feature-selection-fss.md](64-feature-selection-fss.md) - `Fss`: forward subset search.
