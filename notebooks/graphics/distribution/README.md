# Distribution, Relationship, Time-Series, and Export Examples

These plots cover four analytical questions in sequence: the shape of a single variable's distribution, the relationship between variables, ordered/temporal views, and how to export the final chart.

## Distribution Analysis

- [10-distribution-histogram.md](10-distribution-histogram.md) - histogram for binned frequency inspection.
- [11-distribution-density.md](11-distribution-density.md) - kernel density curve for smoothed distribution shapes.
- [12-distribution-boxplot.md](12-distribution-boxplot.md) - boxplot for quartiles, spread, and outliers.
- [13-distribution-boxplot-by-class.md](13-distribution-boxplot-by-class.md) - grouped boxplots for class-wise distribution comparison.
- [14-distribution-density-by-class.md](14-distribution-density-by-class.md) - grouped density curves for overlap and separation inspection.

## Relationships Between Variables

- [20-relationship-scatter.md](20-relationship-scatter.md) - scatter plot for two numeric variables.
- [21-relationship-points.md](21-relationship-points.md) - point plot for discrete or index-based observations without connecting lines.
- [22-relationship-correlation.md](22-relationship-correlation.md) - correlation heatmap for compact association inspection.
- [25-relationship-parallel.md](25-relationship-parallel.md) - parallel coordinates for multivariate profile comparison.
- [26-relationship-pixel.md](26-relationship-pixel.md) - pixel-oriented matrix visualization.
- [27-relationship-dendrogram.md](27-relationship-dendrogram.md) - dendrogram view of hierarchical structure.

## Time-Oriented Views

- [30-time-series-lines.md](30-time-series-lines.md) - multi-line view for ordered series.
- [31-time-series-basic.md](31-time-series-basic.md) - simple exploratory time-series display.
- [32-time-series-forecast.md](32-time-series-forecast.md) - observed series with fit and forecast horizon.

## Export and Delivery

- [40-export-save-pdf.md](40-export-save-pdf.md) - export charts to PDF with controlled dimensions.
- [41-export-save-jpg.md](41-export-save-jpg.md) - export charts to raster formats such as JPG.
