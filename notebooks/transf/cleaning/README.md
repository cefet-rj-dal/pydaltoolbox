# Cleaning and Data Quality Examples

These examples address missing values and unusual observations before the modeling stage begins.

- [10-cleaning-na-removal.md](10-cleaning-na-removal.md) - remove rows with missing values with `NaRemoval`.
- [11-cleaning-outliers-boxplot.md](11-cleaning-outliers-boxplot.md) - detect outliers by the IQR boxplot rule.
- [12-cleaning-outliers-gaussian.md](12-cleaning-outliers-gaussian.md) - flag outliers through Gaussian distance from the mean.
- [13-cleaning-imputation-tree.md](13-cleaning-imputation-tree.md) - `ImputationTree`: tree-based predictive imputation for one target column.
