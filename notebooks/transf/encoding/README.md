# Encoding Examples

These examples change the representation of attributes so downstream learners can consume categorical inputs safely.

- [30-encoding-categorical-mapping.md](30-encoding-categorical-mapping.md) - `CategMapping`: one-hot encoding for categorical variables.
- [31-encoding-hierarchy-cut.md](31-encoding-hierarchy-cut.md) - `HierarchyCut`: create ordered categories from numeric cut points.
- [32-feature-generation.md](32-feature-generation.md) - `FeatureGeneration`: derive new attributes from existing ones.
