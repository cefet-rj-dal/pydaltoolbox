# Sampling Examples

These examples are useful when the first challenge is creating representative partitions before any other transformation.

- [01-sampling-random.md](01-sampling-random.md) - `SampleRandom`: train/test split and folds by simple random draws.
- [02-sampling-stratified.md](02-sampling-stratified.md) - `SampleStratified`: train/test split and folds preserving target proportions.
- [03-sampling-simple.md](03-sampling-simple.md) - `SampleSimple`: direct random extraction of rows or vector elements.
- [04-sampling-balance.md](04-sampling-balance.md) - `SampleBalance`: up-sampling or down-sampling through the sampling interface.
- [05-sampling-groups.md](05-sampling-groups.md) - `SampleGroups`: select entire groups defined by a categorical attribute using cluster sampling.
