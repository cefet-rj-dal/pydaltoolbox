# Dimensionality Reduction and Heuristics Examples

These examples help the reader decide how many dimensions or cut points may be enough for a problem.

- [70-dimensionality-pca.md](70-dimensionality-pca.md) - `DtPca`: principal component analysis for projection and compression.
- [71-curvature-minimum.md](71-curvature-minimum.md) - `FitCurvatureMin`: detect minimum curvature for increasing curves.
- [72-curvature-maximum.md](72-curvature-maximum.md) - `FitCurvatureMax`: detect maximum curvature for decreasing curves.
